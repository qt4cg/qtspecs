PR #3002: 2994 File Module: editorial, minor revisions

Pull request #3002 by ChristianGruen.

Some more minor changes (some of them made explicit): * `file:resolve-path`: normalizes all paths (native separators, ./.. removed) and keeps a trailing separator. `$base` counts as a directory only if it ends with a separator. * `file:write-binary`: `$offset` now defaults to `()`. Without it, the file is replaced; with an explicit `0`, bytes are overwritten in place. * `file:base-dir`: returns the base URI itself if it points to a directory. * `file:copy`/`file:move`: missing parent directories are created, and copying or moving into the source's own directory does nothing. * Renamed parameters: `file:write-text-lines($values)` is now `$lines`; `file:children`/`file:descendants` `$path` is now `$dir`. …and editorial trivia. Closes #2994

PR #2986: 2897 Namespace Axis

Pull request #2986 by ChristianGruen.

Fewer changes than I feared. For XQUF, we proceed as follows: - Generated prefixes: on insert and replace, we switch to a new prefix (`ns0_1`) where XQUF requires `XUDY0023`. - Insert: we drpo namespace nodes in the source. XQUF doesn't mention them, so read literally they would be inserted as children. - Delete: we ignore namespace nodes. XQUF only skips nodes without a parent, so read literally they would be deleted. Closes #2897
